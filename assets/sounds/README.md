# Starter Sound Provenance

The WAV files in this directory were generated specifically for Native
Soundboard on September 12, 2026. They were synthesized locally as mono,
16-bit PCM at 44.1 kHz and do not contain samples or recordings from external
sources.

- `bloom.wav`: layered 523.25 Hz and 659.25 Hz decaying tones.
- `click.wav`: a 1200 Hz transient mixed with deterministic synthesized noise.
- `rise.wav`: a continuous sine sweep from 330 Hz to 880 Hz.
- `low.wav`: layered 164.81 Hz and 220 Hz decaying tones.

License.
